# Benefit

A 9 mm line icon over a two-line outcome, left-aligned, four to a `.pwf-benefits` grid under a "What changes for your team" heading.

**The consumer provides:** an icon and an outcome written from the reader's side, up to eight words.

- Do write outcomes, not features: "Risk signs off the method, not each list", not "Explainability engine".
- Do keep all four the same length, give or take two words.
- Don't centre the captions; the brand sets text flush left.
