# Step

A numbered sequence: an 8 mm square tile with a two-digit mono number, a one-word title and one or two lines. Stacked (`.pwf-steps`) on a trifold panel, in a row (`.pwf-steps--row`) on the one-pager.

**The consumer provides:** three steps (four at most), each a verb and one sentence.

- Do use the product sequence Connect → Signal → Act, or the pilot sequence Connect → Backtest → Review. Name steps with plain verbs.
- Do number with two digits (01, 02, 03) in the tile; never circles or discs.
- Don't use steps for a list that has no order; use `FeaturePanel` or `Benefit`.
