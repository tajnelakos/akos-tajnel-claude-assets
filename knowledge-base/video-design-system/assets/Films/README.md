# Films

The three reference films, one per format, built in code from this system and rendered with [`../../films/render-film.py`](../../films/render-film.py). Their HTML sources are in [`../../films/`](../../films). 1920 × 1080, 30 fps, H.264, captions burnt in, each with an `.srt` sidecar. They ship **silent**: no voice or music is cleared yet (film book, section 13).

| File | Format | Length | What it shows |
|---|---|---|---|
| `story-fixed-rate-dach-16x9.mp4` | Signal story | 48 s | VP of Mortgage Lending, DACH lender: a fixed rate ending, the refinance-risk signal ranked third, its evidence trail, the CRM hand-off, the backtest figure, the end card |
| `walkthrough-evidence-trail-16x9.mp4` | Walkthrough | 30 s | The Evidence Trail feature in four steps: open, weights, export for model risk, audit log; two-line lockup |
| `statement-evidence-16x9.mp4` | Statement | 26.5 s | *Most signals can't explain themselves. Ours show their evidence.* The segment triptych, the figure, the end card |

All figures are labelled illustrative on screen; the lender, customer IDs and data are fictional.
