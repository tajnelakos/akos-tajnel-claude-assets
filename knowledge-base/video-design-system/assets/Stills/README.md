# Stills

One reference frame per pattern, taken from the reference films at the busiest moment of each beat (before its fade-out), at full size. Use them to brief a designer or to check a new cut against the system. The three contact sheets are the pre-render check the film book asks for.

| Still | Pattern |
|---|---|
| `story-titlecard` | TitleCard: hook, parcel field, gold lot, lockup, inverted caption on Navy |
| `story-tension-timeline` | Timeline with the expected part dashed and the outcome marked |
| `story-layerstack` | LayerStack resolving into one moment node |
| `story-momentcard` | MomentCard with rank and its first two evidence rows |
| `story-evidence-trail` | EvidenceTrail with FocusMarks on the top row, the rest dimmed, gold on the top bar |
| `story-action-crm` | CRM queue panel with the synced row in focus and the log line typed |
| `story-proof-figure` | FigureCard on Navy with its source line |
| `story-endcard` | EndCard: lockup, line, action |
| `walkthrough-open` | Survey-grid ground, moments list, focus on one row |
| `walkthrough-step-listed` | Step headline beside the full evidence trail |
| `walkthrough-step-export` | The one click of the film, and its result badge |
| `walkthrough-audit-log` | AuditLog as the reassurance step |
| `walkthrough-lockup` | Two-line lockup on Paper with the gold bar |
| `statement-claim` | StatementStage: claim and turn over the parcel band |
| `statement-segments` | SegmentTriptych under a title |
| `statement-figure` | FigureCard in a Statement |
| `contact-sheet-*` | Each film's check sheet |
