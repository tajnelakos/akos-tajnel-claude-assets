# Logos

The Parcelwise lockup and mark as films use them, redrawn from [`../../../branding-guideline/`](../../../branding-guideline) without the background box the brand's reversed file carries, so they sit straight on the Navy ground.

| File | Use in film |
|---|---|
| `parcelwise-lockup.svg` | Rare: a Paper title frame in a Walkthrough opener, top-left inside the margin |
| `parcelwise-lockup-reversed.svg` | TitleCard (top-left, 360px wide) and EndCard (centred, 420px wide) |
| `parcelwise-mark.svg` | Bottom-right on every Paper frame, 48px |
| `parcelwise-mark-reversed.svg` | Not on Navy frames between the title and the end card; kept for 9:16 cuts with a Navy ground throughout |

One logo per frame. The wordmark is live text set in Archivo 700, so load Archivo wherever these render (films embed it). Outlined versions are the open item in the brand README.
