# AuditLog

The record of everything done with a moment: created, evidence stored, synced, viewed, exported. It is how a Head of Credit Risk film ends its method, and the reassurance beat of a Walkthrough.

**Anatomy.** A ProductPanel titled *Audit log*, rows 64px: timestamp in mono (`2026-11-24 09:14:03`, ISO, never a relative time), the event in mono dot notation (`crm.synced`), the detail in Plex Sans 24px, the actor as a neutral badge (*System*, *CRM*, *Advisor*, never a person).

**Event names** (the product's own): `moment.created` · `evidence.stored` · `crm.synced` · `trail.viewed` · `trail.exported` · `moment.dismissed` · `outcome.recorded`.

**Motion.** Each row fades in, then its event name types at 28ms a character (`type`); rows arrive 0.9 s apart, so the log reads like it is being written as the viewer watches. Hold on the full log.

**Provide.** 3–5 events in time order, the client, the moment.

**Avoid.** Real user names or emails, relative times (*2 min ago*), editing or deleting a row on screen, colour per event.
