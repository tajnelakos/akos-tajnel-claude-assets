Ridge-line motifs drawn for the canvas, each in a navy-ground and a paper-ground version with a transparent background. `ridge-lines` (640 × 640) on covers, anchored top-right; `ridge-strip` (1080 × 144) along the top edge of a data slide; `layer-stack` (560 × 440) for the three data layers on a Moment explainer cover; `scale-bar` (402 × 24) under a limits statement or a source line. One motif per slide, anchored to an edge, never behind text. A motif's gold point is that slide's one gold element.
